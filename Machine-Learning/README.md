## Projects

### 1. Plant Disease Detection Using MobileNetV2

**Description:**

A deep learning project that uses transfer learning with MobileNetV2 to identify plant diseases from leaf images across 38 healthy and diseased plant categories.

**Key Highlights:**
- Used the PlantVillage dataset containing 54,305 images.
- Applied transfer learning using MobileNetV2.
- Achieved 92.57% test accuracy.
- Developed a Streamlit web application called LeafCare.
- Evaluated model performance using precision, recall, and F1-score.

**Technologies:**
Python, TensorFlow, Keras, MobileNetV2, NumPy, Pandas, Scikit-learn, Streamlit.
